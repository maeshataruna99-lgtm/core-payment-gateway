Alur pembayaran QRIS simulasi
Jalur sukses, dengan cabang timeout di langkah 6.
Pelanggan
Merchant
Gateway
PostgreSQL
SandboxPaymentProvider
1. POST /checkout-sessions + Idempotency-Key
2. Simpan checkout dan kunci idempotency
3. Pilih QRIS: POST /payments
4. Commit attempt CREATED
5. Panggil provider, tanpa transaksi DB yang terbuka
6. PENDING + payload QR. Bila timeout: UNKNOWN, lalu cek status
7. Tampilkan instruksi dan QR contoh
8. Callback bertanda tangan HMAC
9. Tolak replay, validasi amount. Satu transaksi: SUCCEEDED + ledger + outbox
10. Webhook HMAC dari outbox, dengan retry
11. Status terbaru: SUCCEEDED
